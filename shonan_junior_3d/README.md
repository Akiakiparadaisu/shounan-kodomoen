# 湘南ジュニア 3Dモデル

## 内容

- `shonan_junior.blend` — Blender 4.2用の編集可能なモデル。部品、素材、カメラ、照明を収録。
- `shonan_junior.glb` — Three.js等で使えるモデル。テクスチャを内包。メートル単位、Y-up。
- `index.html` / `viewer.js` / `vendor/` — Three.js 0.180.0の閲覧サンプル。外観・室内・俯瞰を切替。
- `exterior.png` / `interior.png` / `cutaway.png` — Blenderによる確認用レンダリング。

## 表示の使い方

「外観」「室内」「俯瞰」「水まわり」で視点を切り替えます。「トイレ・沐浴室の扉を開く」で扉が回転し、内部を確認できます。水まわり表示では屋根・天井を外します。`toilet.png`は便所内の参考レンダリングです。

## Blenderで編集

`shonan_junior.blend`を開いてください。メートル設定です。外壁・屋根・天井・窓・建具・家具をコレクション別に管理しています。`Roof`と`Ceiling`を非表示にすると内装を確認できます。`Exterior camera`、`Interior camera`、`Cutaway camera`を収録しています。テクスチャはファイル内にパック済みです。

Web用GLBは、描画負荷を抑えるために部位単位に結合しています。細かな個別編集には.blendを使用してください。GLBにはBlenderの撮影用照明・カメラは含めず、閲覧サンプル側で照明を設定しています。そのためWebとBlenderの見え方は同一ではありません。

## ローカルでサンプルを見る

ファイルをダブルクリックするのではなく、HTTPサーバー経由で開きます。Pythonが使える場合、このフォルダーで以下を実行し、ブラウザーで `http://localhost:8000/` を開いてください。

```sh
python -m http.server 8000
```

Three.jsの必要ファイルをvendorに同梱しているため、外部CDNへ接続する必要はありません。vendorのライセンスは`vendor/LICENSE.txt`を参照してください。

## ホームページに組み込む

独立したビューアーとして使う場合、`index.html`、`viewer.js`、`shonan_junior.glb`、`vendor/`を同じフォルダー構成でWebサーバーに配置します。既存ページから以下のように埋め込めます。

```html
<iframe src="/shonan-3d/index.html"
  title="湘南ジュニア 3D建物モデル"
  style="width:100%;height:720px;border:0;border-radius:16px"
  loading="lazy"></iframe>
```

既存のThree.jsアプリではGLTFLoaderでGLBを読み込みます。

```js
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
new GLTFLoader().load('/models/shonan_junior.glb', ({ scene: model }) => {
  scene.add(model);
  model.traverse((object) => {
    if (['Roof', 'Ceiling'].includes(object.userData.layer)) {
      object.visible = false;
    }
  });
});
```

座標：PDF右側がZ=0付近、正面口はPDF左側のZ=-19.565付近。床がY=0付近。目安として外観カメラ `[-7,7,-29]`、注視点 `[1.75,1.7,-17]`、室内カメラ `[3.1,1.6,-8.75]`。
